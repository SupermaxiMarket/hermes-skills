# 🧠 Pierre's Hermes Skills

Custom skills curated by [Pierre Andre Erard](https://github.com/SupermaxiMarket) for [Hermes Agent](https://hermes-agent.nousresearch.com/).

## Categories

| Category | Skills |
|----------|--------|
| **Content Creation** | daily-ai-brief, social-pulse, video-slideshow |
| **Agent OS** | hermes-oracle, guide-machine, omniroute-management, model-integration |
| **DevOps** | cron-jobs, local-web-deployment, credential-rotation, kanban* |
| **Development** | express-fullstack, spa-app-builder, subagent-driven*, narrative-web-app |

## Install

```bash
hermes skills tap add SupermaxiMarket/hermes-skills
hermes skills list --source SupermaxiMarket
```
