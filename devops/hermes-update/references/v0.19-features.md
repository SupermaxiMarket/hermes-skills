# Hermes v0.19 "Quick Silver" — Feature Details

Source: YouTube tutorial + hands-on upgrade from v0.18 (3235 commits behind).

## Key improvements

### Speed (Quick Silver)
- Response time: ~4s → ~0.9s (80% improvement)
- Applies to all interfaces: CLI, TUI, Telegram

### Live Reasoning
- `display.show_reasoning: true` — model thinking streamed word-by-word
- Previously: spinning wheel with no visibility
- Now: full transparency into tool calls and reasoning chains

### Smart Approvals
- `approvals.mode: smart` — AI judges whether to interrupt
- Use slash-commands to blacklist specific actions: `/deny <pattern>`
- Fewer unnecessary "approve this?" prompts

### Max/Extra High Reasoning
- `agent.reasoning_effort` now supports `max` and `extra_high`
- Previously only: low, medium, high
- Recommended: `max` for deep work profiles

### Secrets Manager
- `hermes secrets bitwarden` — native Bitwarden integration
- `hermes secrets onepassword` — 1Password integration
- API keys no longer stored in plain text

### Session Export
- `hermes sessions export` — export to JSONL, Markdown, QMD
- Full portability: migrate sessions between Hermes instances

### New Bundled Skills (auto-synced to profiles)
- `pdf` — PDF manipulation
- `xlsx` — Excel/spreadsheet support
- `docx` — Word document support

### Sous-Agents Logs
- Sub-agent transcripts now visible in real-time
- Debug delegation chains without guesswork

### Multi-Profile Telegram
- Single Telegram bot can switch between profiles
- Previously needed one bot per profile

- Profile: agent-os-fast (Gemma 4 free) — show_reasoning: false → true
- Global: reasoning_effort: medium → max, show_reasoning: true, approvals: manual → smart
